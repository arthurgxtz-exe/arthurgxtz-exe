## Projetos em destaque

- **[GovSim](https://github.com/arthurgxtz-exe/GovSim)** — simulador educacional de gestão governamental em turnos. Decisões sobre juros, gastos e investimentos alteram indicadores econômicos e podem ter efeitos nos turnos seguintes. O projeto roda offline e combina Java, uma API HTTP local e uma interface em HTML, CSS e JavaScript. O repositório inclui instruções de execução e documentação de testes.
- **[Programação Orientada a Objetos](https://github.com/arthurgxtz-exe/Programacao-Orientada-a-Objetos-POO)** — exercícios em Java sobre classes, encapsulamento e polimorfismo.
- **[Estruturas de Dados I e II](https://github.com/arthurgxtz-exe/Estrutura-de-Dados-I-e-II)** — implementações de estruturas de dados e algoritmos em C.
